# ResearchGate Project Description

## Project title

Polarized Sl-Membrane Cosmology: Branch-Relative Matter Asymmetry and Cold Relic Dark Matter

## Short description

This conjectural research program explores whether the observed matter/antimatter imbalance can be formulated as branch-relative separation rather than net global baryon creation. A higher-dimensional balanced state is proposed to separate through a Sl-membrane phase transition into a visible matter-oriented branch, a conjugate branch, and a neutral residual relic sector. The program preserves local Standard Model physics and focuses on falsifiable constraints: relic abundance, BBN/CMB consistency, `N_eff`, direct detection, neutron-star heating, and astrophysical invisibility of any relic portal.

## Technical summary

The framework proposes a three-output transition:

```text
H_deep -> H_A + H_B + R_Sl
```

where `H_A` is the visible matter-oriented branch, `H_B` is the conjugate branch, and `R_Sl` is a neutral relic residue of the branch-separating order parameter. The observed baryon-to-photon ratio is interpreted as an empirical clock for the Sl transition: annihilation proceeds until Sl condensation separates matter-oriented and conjugate-oriented populations, giving an estimated transition scale near `T_c ~ 38--40 MeV`.

The dark matter question becomes a relic-statistics problem:

```text
m_R n_R ~= 5.3 m_p n_b
```

or, with `kappa_R = n_R/n_b`,

```text
m_R ~= (5.3/kappa_R) m_p.
```

The current open problem is deriving `kappa_R` from Sl projection structure, compact relic statistics, or an index quotient.

## Current status

Conjectural framework; not established physics. The published notes define assumptions, non-claims, and failure conditions. The next step is to compute or exclude the neutral relic sector.

## Looking for

Hostile review, especially calculations or observations that can kill the model quickly. Current weak points: relic statistics, BBN/CMB compatibility, dark-radiation constraints, compact relic formation, recoil conservation, and direct-detection/astrophysical portal limits.
