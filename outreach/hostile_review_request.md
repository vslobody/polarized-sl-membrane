# Hostile Review Request

I am looking for the fastest way to kill this model.

The proposal is a conjectural polarized Sl-membrane cosmology. The core idea is that matter/antimatter asymmetry may be branch-relative rather than globally generated: a balanced deeper state separates into a visible matter-oriented branch, a conjugate branch, and a neutral relic residue.

I am not asking for approval. I am asking for exclusion tests.

The current weak points are:

1. Does the `T_c ~ 38--40 MeV` estimate really follow from annihilation timing and the observed baryon-to-photon ratio?
2. Can branch separation preserve Standard Model gauge neutrality without becoming an ordinary matter/antimatter domain model?
3. Can the neutral Sl relic sector satisfy:

   ```text
   m_R n_R ~= 5.3 m_p n_b
   ```

   without arbitrary tuning?
4. Can `kappa_R = n_R/n_b` be derived from Sl projection statistics or an index quotient?
5. Does a cold Sl relic violate BBN, CMB, `N_eff`, structure formation, self-interaction, neutron-star, or direct-detection limits?
6. If a rare nuclear-recoil portal is proposed, is it already excluded by gas-cloud heating, accretion disks, neutron stars, or xenon limits?

The most useful response is a specific calculation, bound, or reference showing that one of these requirements fails.
